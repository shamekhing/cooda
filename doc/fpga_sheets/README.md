# Tang Primer 20K FPGA reference sheets

Downloaded from the official Sipeed and Gowin documentation sites. This set
covers the board, its GW2A-LV18PG256C8/I7 FPGA, and the DDR3 device used on
the core module.

## Board and DDR3

- `Sipeed_Tang_Primer_20K_Datasheet_V1.0.pdf` — board overview and pin map.
- `Tang_Primer_20K_Dock_3713_Schematics.pdf` — Dock revision 3713 schematic.
- `Tang_Primer_20K_Dock_3714_Schematics.pdf` — Dock revision 3714 schematic.
- `Tang_Primer_20K_Core_DDR3_Datasheet_SKM.pdf` — SK hynix 1 Gb DDR3 SDRAM
  datasheet (`H5TQ1G83EFR` / `H5TQ1G63EFR` families).

## GW2A FPGA

- `Gowin_GW2A_Series_Datasheet_DS102.pdf` — GW2A family electrical and
  performance specifications (Sipeed-hosted English copy).
- `Gowin_GW2A_18_Pinout_UG110.pdf` — GW2A-18 pinout.
- `Gowin_GW2A_Package_Pinout_UG111.pdf` — package and pinout guide.
- `Gowin_Programmable_IO_User_Guide_UG289.pdf` — I/O standards and GPIO.
- `Gowin_Programming_Configuration_Guide_UG290.pdf` — programming and
  configuration.
